Quests lists every quest the game says this character has completed. It is not capped, and it is not only the turn-ins Biography saw.

Quests are grouped by zone. The zone comes from a turn-in Dossier saw, then from Questie when it is installed, otherwise "Zone unknown". A date is shown only when Dossier saw the turn-in. This area limits the list to your current zone.

The site Quests tab stays the full finished list and shows that date when it was stored.
