# Window and commands

Type `/dossier` or left-click the minimap button to open the window. Right-click the minimap button to show or hide the live session panel.

`/aixport` is the old command from when the addon was called AIExport. It still works.

## Tabs

The window has nine tabs down the left side. A feature you turn off on the Options tab also hides its tab. Export, Help, and Options stay.

| Tab | What it is |
| --- | --- |
| Export | The report sections, grouped into cards, and **Create Export** |
| Biography | Your timeline, 40 lines per page |
| Kills | Every creature you have killed, with drops and gold |
| Session | The timer, this session's rates, and the live panel options |
| Shopping | Items and recipes you plan to gather or buy |
| Screenshotter | Automatic screenshots at big moments |
| Ledger, Mail, Professions, Lockouts, Tasks, Quests | Gold, letters, skills, instances, tasks, and completed quests |
| Options | Minimap icon, item stats, detailed export, and a switch for each part |
| Help | The in-game guide, and **Copy guide** |

The same options are in the game's Settings, under **AddOns > Dossier**.

## Commands

| Command | What it does |
| --- | --- |
| `/dossier` | Open the Dossier window |
| `/dossier bio` | Open the Biography tab |
| `/dossier kills` | Open the Kills tab |
| `/dossier session` | Open the Session tab |
| `/dossier panel` | Show or hide the live session panel |
| `/dossier shop` | Open the Shopping tab |
| `/dossier shots` | Open the Screenshotter tab |
| `/dossier shot` | Take a screenshot now |
| `/dossier ledger` | Open the Ledger tab |
| `/dossier tasks` | Open Tasks and the zone window |
| `/dossier options` | Open the Options tab |
| `/dossier settings` | Open Dossier's page in the game's Settings |
| `/dossier help` | Open the in-game guide |

## Turning a feature off

`/dossier off <feature>` stops that part. `/dossier on <feature>` turns it back on. The names you can use:

| You can type | Feature |
| --- | --- |
| `bio` or `biography` | Biography |
| `kills` or `kill` | Kills |
| `session`, `sessions`, or `panel` | Session |
| `shop` or `shopping` | Shopping list |
| `shots`, `screenshots`, `screenshotter`, or `shot` | Screenshotter |
| `companions` or `companion` | Other addons |

Examples: `/dossier off kills`, `/dossier on shop`.

A feature that is off stops watching the game. Its tab is hidden, its section on the Export tab is greyed out with `(off)` and left out of the report, and its commands say how to turn it back on. Nothing it already saved is deleted. The switches apply to every character on the account. Details are on [[Options]].
