# Changelog

## 2.2.13

- Marking a task done greys out that button and changes the line from Due today to Done today. A small Undo under the button puts it back on the schedule.

## 2.2.12

- A task can repeat each month or each year, as well as each day, each week, or just once. Marking it done keeps it done until that month or year ends.
- Each note has a title and a body. Two notes sit on a line, and the body wraps so the whole note shows.

## 2.2.11

- Notes are their own tab. Each note is a box you can add, edit, or delete. The Tasks tab and the task panel no longer hold notes.

## 2.2.10

- The task panel uses the same choices as the session panel: show it, lock it, pick which lines, and set the background. The lines are colored instead of plain text.

## 2.2.9

- The Quests tab is gone. Dossier no longer records a completed-quest list. Saved rows stay. Questie still has the journey, on the site and in game. A turn-in is still a Biography line, and it can still mark a task done.
- Each task can be marked done for the day or the week, edited, or deleted. The list says "Due today" and "Done this week" instead of "open" and "daily".
- Notes on the Tasks tab are boxes you can add, edit, and delete.

## 2.2.8

- The Professions tab is gone. Dossier no longer records skill ranks. Saved rows stay. Altoholic still shows them on the site, and opening a profession window still fills the recipe section of an export.
- The window is shorter, and each tab sits inset from both sides of the rail so the labels that remain fit.
- Options lists the switches that are still in the addon: Biography, Kills, Session, Mail, Lockouts, Tasks, Quests, Shopping list, Screenshotter, and Other addons.
